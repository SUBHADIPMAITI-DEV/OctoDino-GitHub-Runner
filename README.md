# 🎮 About The Game

**OctoDino** is a modern cyberpunk-inspired endless runner game based on the classic Chrome Dino game — fully redesigned with GitHub and coding culture aesthetics.

Play as a glowing **Octocat-Dinosaur hybrid** and survive an infinite world of:
- 🐞 Flying bugs
- ⚠ Merge conflicts
- 📦 Pull request blocks
- 💥 Repository crashes

Collect GitHub Stars ⭐, achieve high scores, and survive the coding apocalypse.
